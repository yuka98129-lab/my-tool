# My Tool

日々のタスクを自動化し、チームの生産性を最大化するためのシンプルな Web ツールです。

## 概要

My Tool は、繰り返し作業の削減とチームの連携強化を目的として作られた軽量ツールです。ブラウザだけで動作するため、インストール不要ですぐに使い始めることができます。

## 使い方

1. `index.html` をブラウザで開く
2. 必要な操作をその場で実行する
3. 結果を確認・共有する

ローカルで起動する場合:

```bash
# リポジトリをクローン
git clone https://github.com/yuka98129-lab/my-tool.git
cd my-tool

# index.html をブラウザで開く
open index.html
```

## ファイル構成

```
my-tool/
├── index.html   # メインのランディングページ
└── README.md
```
